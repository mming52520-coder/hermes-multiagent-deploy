# 中文网页与按键说明

本地中文包首次打开会选择 Hermes 原生「简体中文」，导航、常用页面和工作流按钮均使用中文。左侧选择「工作流」进入「研发工作台」；右上或侧栏底部的语言按钮可切换语言，之后保留你的选择。

## 页面怎么用

1. 点击左侧的执行目标，打开详情。
2. 在「执行概览」点击调查、开发、独立审查、最终汇总，查看对应任务。
3. 在「验收证据」核对验证结果、退出码、日志与候选变更。
4. 在「整改记录」查看失败分类、历史轮次和预算。
5. 展开页面顶部「使用说明与按键」，随时查看同一份操作提示。

概览新增「下一步」指引和四阶段进度，按当前任务与验收状态说明等待、审批、冻结候选、处理阻塞或核对证据。中断后的任务放行可继续使用原来的授权或审查操作；建议不会自动执行，也不能绕过后端核验。阶段全部完成与交付已验收分别显示。

列表、选中详情和打开的证据页每 20 秒一并同步，保留当前页签与角色选择。顶部显示最近成功同步的时间。同步失败时保留该目标上次成功读取的数据并提示重试，操作按钮暂停；切换目标后不会显示另一个目标的旧详情或同步时间。

没有执行记录时显示空列表；安装插件不会自动创建或运行项目任务。安装器默认只读，操作员开放后显示「人工受控」。本地审阅实例已开放创建和审批；启动按钮还会检查 Docker、四个角色、源版本和执行配置，缺依赖时仍禁用。

先「新建目标」填写范围和验收标准，再查看目标和源版本，点击「人工审批」勾选确认。审批只记录授权。准备项全部就绪后，另点「启动多 Agent」并再次确认，才会交给原生调度器。模型调用可能产生费用；创建和审批均不会调用模型。

准备清单默认收起，标题显示待完成项数；点击可展开。审批/启动弹窗列出目标、源版本和轮次，后台拒绝已经过期的轮次确认。创建后的检查清单显示本轮角色配置副本，后续补凭据时请使用对应 Profile。

## 按钮说明

| 按钮或控件 | 作用 | 只读模式 |
|---|---|---|
| 四个 Agent · 统一模型配置 | 主界面直接编辑四行角色，不打开配置弹窗 | 操作员开放后显示 |
| 获取全部模型 | 导入四行各自的 Key，分别读取所选厂商的模型列表；不改变模型选择 | 不可用 |
| 获取模型 | 只导入并获取这一行的模型列表 | 不可用 |
| 一套连接应用全部 | 在同页快捷区把一个厂商和 Key 填到四行；获取模型并统一保存后应用 | 不可用 |
| 自定义兼容 API | 填写接口和模型，选择 Chat Completions、Responses 或 Anthropic Messages | 不可用 |
| 选择模型弹窗 → 配置 API / 密钥 | 内置厂商只需填写当前配置档的 Key，底部点「导入密钥并获取模型」，从刷新目录选择后点「切换」 | 原生页面沿用 Hermes 权限 |
| 选择模型弹窗 → 高级设置 | 自定义地址、模型与协议；内置厂商的标准接入无需填写 | 原生页面沿用 Hermes 权限 |
| 选择模型弹窗 → 新增自定义 API | 新建命名连接，填写 API 地址、模型、可选密钥与协议 | 原生页面沿用 Hermes 权限 |
| 保存模型配置 | 一次保存所有修改的角色；可使用不同厂商和模型，同步到未启动目标时撤销旧审批 | 不可用 |
| 刷新 / 重新读取 | 同步列表、当前详情和证据；失败后可重试，不会启动任务 | 可用；同步期间暂停重复点击 |
| 搜索研发目标 | 按目标名称筛选记录 | 可用 |
| 全部 / 需要关注 | 显示全部记录，或仅显示阻塞、记录缺失的目标 | 可用 |
| 四阶段卡片 | 查看对应任务的编号、角色与运行结果 | 可用 |
| 查看阻塞阶段 | 定位阻塞的角色卡片并移动键盘焦点，查看该任务详情 | 有阻塞时可用 |
| 查看验收证据 | 从下一步指引进入当前目标的证据页 | 可用 |
| 执行概览 / 验收证据 / 整改记录 | 切换详情页 | 可用 |
| 查看验证日志 | 展开最近 16 千字节原始日志 | 有证据时可用 |
| 新建目标 | 创建待审批计划，不会立即运行 | 不可用 |
| 人工审批 | 记录当前目标、源版本和轮次的人工授权，不释放任务、不调用模型 | 不可用 |
| 启动多 Agent | 已审批且依赖就绪后，连接/启动原生 Gateway 并按依赖派发；可能产生模型费用 | 不可用 |
| 配置角色和模型 / 系统设置 | 查看并准备执行环境；创建目标后请按清单中的本轮 Profile 配置 | 原生页面沿用 Hermes 权限 |
| 准备独立审查 | 冻结开发候选并释放审查任务 | 不可用 |
| 验证开发结果 | 在独立容器运行操作员预设验收命令并保存结果 | 不可用 |
| 验证审查副本 | 对审查副本运行独立验证 | 不可用 |
| 提交质量验收 | 核对版本、变更、两份证据和审查结果；任务完成不等于验收通过 | 不可用 |
| 创建整改轮次 | 对已完成且未通过的审查创建受限整改轮次，新轮次需重新授权 | 不可用 |
| 取消 / 关闭 | 关闭尚未执行的弹窗或提示 | 可用；操作处理中需等待 |

## 键盘说明

| 按键 | 作用 |
|---|---|
| Tab | 移动到下一个可操作控件；禁用按钮不会获得焦点 |
| Shift + Tab | 移动到上一个可操作控件 |
| Enter / 空格 | 在按钮或折叠说明标题上确认、展开或收起；输入框保留正常输入行为 |
| Esc | 关闭操作确认弹窗；处理中不会撤销正在执行的后台操作 |
| 确认勾选框 | 有副作用的操作必须明确勾选，再点击「确认操作」；不能绕过只读和后端检查 |

未新增全局单键快捷键，不会在输入目标时误触任务操作。

## 状态说明

| 状态 | 含义 |
|---|---|
| 待审批 | 已登记，尚未获准执行 |
| 已审批待启动 / 待启动 | 当前轮次已有人工授权，尚未启动调查和开发 |
| 待准备审查 | 本轮已审批，审查和汇总仍等待冻结候选副本 |
| 未就绪 | 页面顶部显示缺少的准备项；创建和审批仍可进行 |
| 等待依赖 | 等待前置任务完成 |
| 待执行 / 执行中 | 已具备执行条件 / 当前正在运行 |
| 已阻塞 / 记录缺失 | 需要查看详情并由操作员处理 |
| 已完成 | 该任务结束，不能单独证明交付合格 |
| 可提交验收 / 已验收 | 证据满足受控验收条件 / 已留下有效验收记录 |
| 尚无证据 | 尚未生成可信验证记录，不能当作验证通过 |
| 同步失败 | 当前数据尚未刷新成功；已有内容保留并标记，操作暂停至重新同步成功 |

命令、版本号、任务编号、文件路径、用户填写内容和原始验证日志保留原文。界面翻译不会修改证据、代码、模型配置或任务状态。

如果仍显示英文，先确认启动时 HERMES_WEB_DIST 指向新版中文包的 web_dist，然后刷新该页面；也可以点击页眉「中文」。更新插件后需重新加载对应 Dashboard 页面。
