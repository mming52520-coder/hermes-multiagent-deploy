## 2026-11-06 文档格式误判与语义核验

- 只调整 Tester/Reviewer 的既有 SOUL：自由文本不使用臆造的标题、句式或数字拼写断言；明确格式仍检查。Tester 将内容要求与独立预期交给 Reviewer，Reviewer 先摘录实际字段、数值、原文与单位，再复算比较，核查矛盾和遗漏。
- 上游设计和检查清单不能扩大原任务的验收条件；关键结果的表头单位、字段对应和否定含义属于内容正确性，不按风格问题忽略。平台测试失败、独立审查及最终验收门禁均保留。

- 使用原始旧对话的隔离副本及同一 `gpt-6-luna / medium` 配置回放：旧版仍拒绝；修复后询问能力不建任务，明确的新任务产生真实授权和 `RUNNING_RESEARCH` 状态，无发布权限时不建任务。Worker 调度与外部消息使用替身，未向真实飞书群发送验证消息；单次回放不代表成功率统计。
